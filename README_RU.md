# Романтическое приглашение — инструкция

## Что входит
- Нежно-розовый адаптивный сайт с сердечками.
- Кнопка «Нет» убегает, «Да» увеличивается.
- Одноразовый ответ, который проверяется на сервере в SQLite.
- Уведомление в Telegram при нажатии «Да».

## 1. Создай Telegram-бота
1. Открой Telegram и найди `@BotFather`.
2. Отправь `/newbot`, следуй инструкциям и скопируй токен бота.
3. Открой чат с созданным ботом и нажми **Start**.
4. Чтобы узнать свой chat ID, открой в браузере адрес ниже, заменив `BOT_TOKEN` токеном:
   `https://api.telegram.org/botBOT_TOKEN/getUpdates`
5. В ответе найди `"chat":{"id":123456789...}`. Это твой `TELEGRAM_CHAT_ID`.
   Если `result` пустой, отправь боту ещё одно сообщение и обнови страницу.
6. Никому не показывай токен бота и не вставляй его в `index.html`.

## 2. Опубликуй сайт на Render
1. Создай аккаунт на https://render.com/ и GitHub на https://github.com/.
2. Распакуй архив и загрузи все файлы папки `onlyteplo_invite` в новый GitHub-репозиторий.
3. На Render выбери **New → Blueprint**, подключи репозиторий и подтверди создание сервиса из `render.yaml`.
4. В настройках сервиса → **Environment** добавь:
   - `TELEGRAM_BOT_TOKEN` = токен из BotFather
   - `TELEGRAM_CHAT_ID` = твой chat ID
   `INVITE_TOKEN` генерируется автоматически, `DB_PATH` и диск описаны в `render.yaml`.
5. Дождись успешного развёртывания. У сервиса появится адрес вроде `https://my-date-invitation.onrender.com`.
6. Персональная ссылка выглядит так:
   `https://ТВОЙ-САЙТ.onrender.com/?t=ЗНАЧЕНИЕ_INVITE_TOKEN`
   Скопируй значение `INVITE_TOKEN` из Environment и подставь в ссылку. Отправь её только нужному человеку.

## 3. Важные настройки
- Сервис должен иметь постоянный диск, иначе после перезапуска может потеряться состояние одноразового приглашения. `render.yaml` задаёт диск на платном плане; проверь актуальную стоимость и доступность дисков в Render перед публикацией.
- Не публикуй `INVITE_TOKEN` отдельно и не размещай персональную ссылку публично: любой обладатель ссылки может ответить.
- Ответ расходует приглашение до отправки Telegram-сообщения. Если Telegram временно недоступен, повторно ответить по той же ссылке нельзя; проверь журнал сервиса.
- Сейчас кнопка «Нет» специально убегает и не позволяет выбрать отказ. Если важно оставить человеку полноценный выбор, лучше сделать обычную кнопку «Нет».
- Для нового приглашения сбрось поле `used` в базе данных через защищённый административный способ либо создай новый экземпляр/базу и новый токен. Не редактируй базу вручную, пока сервис работает.

## Локальный запуск для проверки
Требуется Node.js 20+.
```bash
npm install
INVITE_TOKEN=change_this_to_a_long_random_token \
TELEGRAM_BOT_TOKEN=your_bot_token \
TELEGRAM_CHAT_ID=your_chat_id \
npm start
```
Открой `http://localhost:3000/?t=change_this_to_a_long_random_token`.

## Ограничения
- Эта версия уведомляет тебя только о принятии приглашения, потому что кнопка «Нет» убегает.
- Одноразовость действует на сервере и между обновлениями страницы. Для надёжного сохранения состояния необходим постоянный диск или внешняя база данных.
